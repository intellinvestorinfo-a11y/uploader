Privacy Policy

Last updated: 17 November 2026

"Intelligent Investor Uploader" is a personal tool operated by the owner of the "Intelligent Investor" channel. It is used only to upload the owner's own educational videos to the owner's own TikTok account. It is not offered to the public.

What the tool accesses

  • When the owner logs in with TikTok, the tool receives an access token and basic profile information (display name) so it knows which account to post to.
  • The tool sends the owner's finished video file and caption to TikTok.

What the tool does not do

  • It does not collect data about other TikTok users.
  • It does not post on behalf of anyone other than the owner.
  • It does not sell, share or advertise with any data.

Storage

The access token is stored only on the owner's own computer. No data is stored on any server operated by the tool.

Revoking access

The owner can remove the tool's access at any time in TikTok under Settings and privacy, Security and permissions, Apps and services.
